{\fBody
	The tutorial uses HPC resources at \textcolor{fzjred}{\bfseries Jülich Supercomputing Centre}.
	The following steps are needed to access the JUPITER machine. Feel free to start
	them as soon as you sit down. Ask the tutors in the room for help.\par}
\vfill

% ---------- the seven steps, one column ----------
\begin{enumerate}[label={\color{fzjblue}\bfseries\arabic*.}, leftmargin=7mm,
	itemsep=3mm, topsep=0pt, parsep=0pt, before={\fBody}]
	\item Create a \kw{JuDoor} account and \kw{join} the \mono{training2660} project:
	      \lnk{https://go.fzj.de/mg-jd}{go.fzj.de/mg-jd}
	\item Fill in the \kw{usage agreement} (JUPITER); wait at least 15\,minutes for
	      synchronization
	\item Log in to \kw{Jupyter}: \lnk{https://go.fzj.de/mg-jup}{go.fzj.de/mg-jup}
	      (JuDoor credentials such as \mono{usr1})
	\item Create a new Jupyter \kw{instance} on JUPITER using \mono{LoginNode}
	      and the training project (fields pre-filled)
	\item In a Jupyter terminal, \kw{source} the course environment:\\
	      \cmd{source \$PROJECT\_training2660/env.sh}
	\item \kw{Sync} the course material:\\
	      \cmd{jsc-material-sync}
	\item \emph{Optional}: Download and install \kw{Nsight Systems}
\end{enumerate}
